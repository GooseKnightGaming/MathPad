LaTeX+

Your own layer on top of LaTeX. It's expanded inside maths before rendering, and "Copy plain LaTeX" turns it into ordinary LaTeX for anywhere else. Your rules override standard LaTeX commands of the same name.

How MathPad works

  • Write prose normally. Put maths in $ … $ (inline) or $$ … $$ (display). \[ … \], \( … \) and bare \begin{align*} … \end{align*} work too.
  • Prose formatting: # Heading, ## Subheading, **bold**, *italic*, `code`, lines starting - become bullets, blank line = new paragraph.
  • Symbols (or Ctrl+/) opens the palette. Clicking inserts at the cursor, and wraps it in $…$ if you're not already in maths. If you've selected something, it goes into the first slot.
  • Tab jumps to the next empty slot (an empty {} or an empty matrix cell); Shift+Tab goes back.
  • Matrices: \mat{1,2;3,4}. Commas split columns, semicolons split rows. \bmat gives square brackets, \vmat a determinant, \aug{1,2|5;3,4|6} an augmented matrix. Or use the Matrix tab in Symbols to pick a size.
  • Evaluating: [x^2]_0^1 becomes properly sized brackets with limits. \eval{x^2}{0}{1} does the same.
  • Bare words: int_0^1 (2x) dx = [x^2]_0^1 = 1 works as typed. Edit the list under LaTeX+.
  • Copy plain LaTeX expands all LaTeX+ for Overleaf, Google Docs' equation box, or a chat with Claude. File → Export LaTeX document gives a whole .tex file.
  • Sheets live in this browser. Use File → Back up everything now and then.
  • On a Chromebook you can install MathPad as an app (the install icon in Chrome's address bar), and it then works offline.
