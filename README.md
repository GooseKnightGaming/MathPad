# MathPad

A LaTeX scratchpad: type LaTeX on the left and see it rendered live on the right, or click symbols from a palette.

**Use it:** https://gooseknightgaming.github.io/MathPad/

## Features
- Live MathJax rendering of `$inline$` and `$$display$$` maths, with light Markdown for the prose (`#` headings, `**bold**`, `*italic*`, `- ` bullets)
- Symbol palette (Ctrl + /) with Greek, structures, calculus, relations, sets & logic, arrows, and a matrix size picker
- Tab jumps to the next empty slot (`{}` or an empty matrix cell)
- **LaTeX+**: your own macros (`\R`, `\diff{y}{x}`, `\0`…) and shorthands (`<=`, `!=`, `int`, `dx`…), editable in the app
- Built-ins: `\mat{1,2;3,4}`, `\bmat`, `\vmat`, `\aug{1,2|5;3,4|6}`, and evaluation brackets `[x^2]_0^1`
- Copy plain LaTeX (all LaTeX+ expanded), export a full `.tex` document, save/open sheets as `.md`, back up everything as JSON
- Installable and works offline (Chrome: install icon in the address bar)

Sheets are stored in your browser's local storage, so back up now and then.
